# Sejel-Kashfe
is a cross-paltform application designed for event management, skill tracking, and meeting badge requirements for scout groups. Many scout leaders and members have a hard time organizing activities, tracking achievements, researching sources to learn a specific skill, or staying connected within a single circle. This app provides a centralized platform where scouts can access schedules for upcoming events, log their progress, earn digital badges, and compete for weekly rankings.

```Goals:```
1.	User-friendly Interface: ensuring easy navigation for all users.
2.	Communication Tools: between scouts, leaders, and parents.
3.	Event Planning and Tracking: Easily manage events, track attendance, and log activities
4.	Skill Development: Access learning resources and progress tracking for skill development.
5.	Digital Badge System: Earn badges for achievements, with a game-like experience encouraging progress.
